# Security reports

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/ark4ez/github-web-panel/security/advisories/new).

Include the plugin version, Rider build, operating system, expected behavior, and minimal reproduction using synthetic data or a public repository. Describe the affected boundary (for example, external navigation or session handling). Do not send working credentials, cookies, OTPs, signed download URLs or private repository content.

Do not open a public issue containing exploit details or credential exposure. The maintainer will coordinate disclosure through the private report. There is no guaranteed response time or paid support agreement.

## Supported versions

Security fixes target the latest beta on `main`. Earlier prototypes are unsupported. The declared runtime is local Rider 2026.2.1 / 262.* on Windows with the bundled JetBrains Runtime and JCEF plugin; see [README.md](README.md) for exact scope.

See [PRIVACY.md](PRIVACY.md) for session storage, browser permissions and data flow. Open source is not a security certification.
